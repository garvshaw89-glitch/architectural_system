## 6. MATERIAL MATRIX

1. **Material 01 — The Void:**
   - Color: `#050505`
   - Purpose: Non-reflective absorbent deep space. Grounds the luxury feeling through expansive negative space.
2. **Material 02 — Glass Membrane:**
   - Properties: `background: rgba(18, 20, 23, 0.70)`, `backdrop-filter: blur(16px)`, `border: 1px solid rgba(255, 255, 255, 0.07)`
   - Purpose: Floating navigation bar, modal inspectors, interactive HUD controls.
3. **Material 03 — Electric Light:**
   - Properties: `box-shadow: 0 0 35px -5px rgba(124, 92, 255, 0.25)`
   - Purpose: Controlled luminescence for active cursor states, the Identity Core orbital nodes, and focused inputs.
4. **Material 04 — Technical Surface:**
   - Properties: 64px major grid, 24px minor grid hairlines (`rgba(255, 255, 255, 0.03)`).
   - Purpose: Subtle architectural grid expressing engineering discipline without cluttering content.

## 7. TYPOGRAPHY ARCHITECTURE & THE 2+1 RULE

Typography pairs high-character display geometry with Swiss editorial precision and monospace data discipline:
- **Display Face:** `Syne` (Weights: 700 Bold, 800 ExtraBold) — Confident, sculptural, architectural.
- **Body Face:** `Plus Jakarta Sans` (Weights: 400 Regular, 500 Medium, 600 SemiBold) — Neutral, human, ultra-legible.
- **Technical Monospace Outlier:** `JetBrains Mono` (Weight: 500 Medium) — Tabular numerals, indices, parameters.

### Typographic Hierarchy Scale:
- **Level 01 — Hero Anchor:** `Syne 800`, 64px–96px, `-0.03em` tracking, `text-wrap: balance`. Example: `BUILDING INTELLIGENT SYSTEMS.`
- **Level 02 — Section Chapter:** `Syne 700`, 32px–40px, `-0.02em` tracking. Example: `FEATURED ARCHITECTURE`
- **Level 03 — Project Heading:** `Syne 700`, 22px–28px, `-0.01em` tracking. Example: `AROGYASEVA HEALTH ENGINE`
- **Level 04 — Body Prose:** `Plus Jakarta Sans 400/500`, 15px–16px, `1.65` line-height, `65ch` max width.
- **Level 05 — Technical Index:** `JetBrains Mono 500`, 11px–13px, uppercase, `+0.05em` letter-spacing. Example: `01 / SYSTEMS · AI NATIVE`

## 9. CURSOR SYSTEM & BEHAVIOR SPECIFICATION

The cursor is a persistent intelligent guide:
- **Inner Core:** 4px high-luminance light point (`#F5F5F0`).
- **Outer Aura:** 32px translucent circle with soft lerp dampening.
- **Behavior Matrix:**
  1. `Default`: 4px point + 32px soft ring.
  2. `Link`: Ring expands to 48px, subtle violet glow.
  3. `Button`: Magnetic adhesion snapping to button centroid.
  4. `Project`: 72px ring displaying `OPEN ↗`.
  5. `Image / Media`: 72px ring displaying `EXPLORE`.
  6. `Drag Canvas`: Ring with directional arrows `DRAG ↔`.
  7. `Disabled`: Muted opacity, ring constricts.

## 10. MOTION PERSONALITY & TIMING BUDGETS

Animations adhere to physical elegance (no cartoon bounce or rapid spins):
- **Micro (150–250ms):** Hover states, button transitions, micro-feedback (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Normal (400–700ms):** Card expansions, tab switching, drawer navigation.
- **Cinematic (800–1400ms):** Hero viewport reveals, Identity Core morph cycles (`cubic-bezier(0.22, 1, 0.36, 1)`).
- **Ambient (4–15s):** Slow orbital drifts, atmospheric light shifts, background grid shimmer.
