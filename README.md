## 🛠️ Quick Start & Local Development

### Prerequisites
* **Node.js**: v18.0.0 or higher (v20+ recommended)
* **npm** or **bun** / **pnpm**

### Installation
```bash
# Clone the repository
git clone https://github.com/garvshaw89-glitch/digital-architecture-portfolio.git

# Enter project directory
cd digital-architecture-portfolio

# Install production and development dependencies
npm install

# Start local development server with Vite
npm run dev
```

The application will be live at `http://localhost:3000`.

### Production Build & Verification
```bash
# Run strict TypeScript and lint validation
npm run lint

# Build production-optimized bundles
npm run build

# Preview production build locally
npm run preview
```
